# SQL Fundamentals

This section focuses on the foundations of writing precise SQL queries for relational databases.

## Concepts Covered

* `SELECT` — retrieving required columns
* `DISTINCT` — eliminating duplicate values
* `WHERE` — filtering rows
* `AND / OR` — combining conditions
* `IN / NOT IN` — filtering against a set of values
* `BETWEEN` — filtering within a range
* `LIKE` — pattern matching
* `ORDER BY` — sorting query results
* `LIMIT` — restricting the number of returned rows

## Practical Focus

The exercises use an e-commerce order dataset to practice translating business requirements into SQL queries.

The emphasis is on understanding **what the requirement asks**, selecting the appropriate SQL construct, and writing precise queries.
