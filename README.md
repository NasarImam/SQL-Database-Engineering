# SQL & Database Engineering

A structured journey to build strong SQL and relational database engineering skills, with a focus on practical querying, backend development, and real-world data-intensive systems.

This repository documents the progression from SQL fundamentals to advanced database concepts through hands-on problems, engineering scenarios, and practical case studies.

## Progress

### SQL Fundamentals — In Progress

* Data retrieval with `SELECT`
* Filtering with `WHERE`
* Removing duplicates with `DISTINCT`
* Combining conditions with `AND` / `OR`
* Filtering sets with `IN` / `NOT IN`
* Range filtering with `BETWEEN`
* Pattern matching with `LIKE`
* Sorting with `ORDER BY`
* Result limiting with `LIMIT`
* E-commerce order querying

More sections will be added as they are completed.

## Engineering Approach

Each concept is learned through:

1. Understanding the underlying SQL concept
2. Understanding when and why it should be used
3. Solving practical problems
4. Applying the concept to realistic engineering scenarios
5. Reviewing query correctness and edge cases


The repository is organized by **engineering capability rather than study day**, reflecting the skills and concepts developed over time rather than a daily learning log.
